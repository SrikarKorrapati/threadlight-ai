THREADLIGHT / PERSONAL COMPANION

A thoughtful second draft.

Connect your local OpenAI service, then return to your conversations.

01 / YOUR OPENAI CONNECTION

Start with the local service.

Run npm start in the Threadlight folder. Add your OpenAI API key in the local setup page. Your key stays on your computer and is used by the service to call OpenAI.

Open local setup ↗
02 / PAIR THIS EXTENSION

A private connection to your browser.

Use the pairing token here, not your OpenAI key.

Memory is separated by this label and each chat’s identity. If you switch WhatsApp accounts in this browser, change this label before using the assistant.

03 / YOUR FIRST CONVERSATION

Stay in the conversation.

  1. Open WhatsApp Web and reload the page after installing the extension.
  2. Select a draft or message, then choose Ask Threadlight. Give it your own instructions.
  3. Use Suggest a reply for three possible responses based on this conversation.
  4. Choose a suggestion to insert as a draft. Send it yourself when ready.

Shortcut: Alt + Shift + W. Media: download a WhatsApp attachment, then attach it in Threadlight. You can also paste an image. Calendar actions open a prefilled event for you to save.

Open WhatsApp Web ↗
Messages are remembered while the panel is open. Only requested generations send context to OpenAI. History, preferences, and writing feedback are stored in this browser profile; use your operating system’s disk protection for data at rest.
